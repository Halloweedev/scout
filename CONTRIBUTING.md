# Contributing to Scout

Scout welcomes focused contributions that keep the product fast, local-first, familiar, and keyboard-first.

## Workflow

1. Open or reference an issue for substantial behavior changes.
2. Keep changes scoped to one clear problem.
3. Run `pnpm build` and `cargo check --manifest-path src-tauri/Cargo.toml` before submitting.
4. Include platform notes for filesystem behavior that differs on macOS, Windows, or Linux.
5. Prefer small, reviewable commits with descriptive messages.

## Product guardrails

Preserve the permanent left sidebar, familiar filesystem hierarchy, monochrome black/charcoal visual system, custom SVG icons, progressive disclosure, and fast keyboard flow. Avoid dashboard cards, SaaS layouts, blue tech accents, fake Unicode icons, excessive pills, and decorative glass.

By contributing, you agree that your contribution is distributed under GPL-3.0-only.
